# Case v7.2 (9.5 mm switches) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the v7 case and the printed carrier work with 6x6x9.5 tact switches: taller caps with no bridges, board clips that hold, and spacers on the carrier.

**Architecture:** All case geometry is OpenSCAD in `case/v7/*.scad`, rendered by `case/v7/export.sh` into `case/stl_v7/` and checked by `case/tests/test_v7.py` (pytest + trimesh) and `case/fit_check_v7.py`. The carrier is Python (shapely + trimesh) in `pcb/make_carrier_stl.py`.

**Tech Stack:** OpenSCAD 2021.01, Python 3.13 via uv (`uv run --python .venv/bin/python`), trimesh, manifold3d, shapely, pytest.

**Spec:** `docs/superpowers/specs/2026-11-24-case-v7.2-tall-switch-design.md`

## Global Constraints

- `sw_body 3.8`, `sw_total 9.5`, `cap_proud 4.0`; hex bore `grip_af 3.4` kept, its depth follows `sock`.
- Switch-body pocket: 6.6 square, vertical `pocket_h` = 0.6 (caps, sectors, OK) / 1.0 (rockers), then a 45 deg roof to the bore. No horizontal ceiling wider than the bore.
- Clip hook: flat ledge at z = `bb_z0`, a 0.6 x 45 deg lead-in facing the back, `len = pz0 - bb_z0 + 0.8`.
- Spacers: d 4.0, top 0.1 under the face's underside, at board (17.0, 3.5), (6.5, 39.0), (35.0, 41.5), (6.5, 100.5), (32.0, 102.0).
- Board outline stays 43.0 x 112 x 1.6.
- Release: `release/v7.2/`, the whole set plus SHA256SUMS.txt and a zip. Upload to copyparty `/stl/v7.2/` (the user asked).

## Review Focus

- A pressed or tipped rocker must not touch a switch body: covered by `test_caps_clear_switch_bodies` (pressed + tilt assemblies).
- A spacer must not land on a cap, the D-pad ring or a rocker fulcrum: covered by `test_spacers_land_on_the_face`.
- The board snaps past the hooks from the back: fit_check's insertion sweep (board narrowed 1.3) must stay green.
- The clip bottom must still clear the battery: fit_check component collision.
- The plunger must reach the cap's bore with ceiling >= 1.0: `test_plunger_fits_bore`.
